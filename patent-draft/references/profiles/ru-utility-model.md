# Russian utility-model drafting profile

Use this profile only after the user has selected a Russian utility model. Do not
infer it merely because an implementation is a device. It supports new drafting,
supported revision, and EN-to-RU translation/adaptation.

Read, in order:

1. [../ru/source-manifest.md](../ru/source-manifest.md) and
   [../ru/authority-and-verification.md](../ru/authority-and-verification.md);
2. [../ru/core-drafting.md](../ru/core-drafting.md);
3. [../ru/utility-model-drafting.md](../ru/utility-model-drafting.md);
4. [../ru/terminology.md](../ru/terminology.md) when drafting IT or translating;
5. [../ru/translation-review.md](../ru/translation-review.md) only in
   `translate_adapt` mode.

Apply the common evidence, claim-first, and deliverable contracts. Enforce the
device-only object, exactly one independent claim, and the ban on alternative
essential features in that independent claim. If the supplied material instead
requires a method, CRM, or multiple independent objects, preserve it as evidence,
identify the mismatch, and ask whether to use `ru-invention`; never switch profiles
silently. Complete the verification gate before a filing-facing handoff and return
the completed `ru-rule-check.md` with the drafting packet.
