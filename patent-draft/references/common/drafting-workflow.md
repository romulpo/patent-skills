# Drafting workflow

Use this sequence for a new draft, supported revision, or translation/adaptation.

1. Select the explicit profile, drafting mode, document language, and filing
   context.
2. Inventory the supplied evidence and mark missing facts. Preserve original files.
3. Build the invention thesis with a causal chain from technical features to the
   stated result.
4. Create the claim plan and support map before drafting a complete description.
5. Draft independent claims, limitation tables, and dependent fallback positions.
6. Draft the description to support the claims and authentic disclosed variants.
7. Prepare the abstract, terminology map, drawings brief, and reference-numeral
   table required by the selected profile.
8. Check dependencies, support, terminology, numbers, figures, and unresolved
   inventor decisions.
9. Return the complete drafting packet described in `deliverable-contract.md`.

Do not treat a fluent draft as complete when evidence, support, or inventor choices
remain unresolved.
