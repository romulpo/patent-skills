# RU terminology controls for IT and devices

These are drafting defaults from the supplied translation guides, not mandatory
one-to-one translations. Choose the term that accurately reflects the evidence,
record it in the terminology map, and use it consistently.

| Source concept | Typical Russian term | Control |
|---|---|---|
| method / process | `способ` | confirm that the claimed object is a method |
| system / device | `система` / `устройство` | choose the correct generic concept; do not alternate stylistically |
| computer-readable medium | `машиночитаемый носитель` | invention profile only; do not import into a utility model |
| processor / processing unit | `процессор` / `процессорный блок` | distinguish only if the source does |
| memory / storage | `память` / `запоминающее устройство` | preserve functional and structural distinctions |
| module / unit / block | `модуль` / `блок` / `узел` | do not use as interchangeable synonyms without support |
| interface | `интерфейс` / `блок сопряжения` | select by disclosed structure and function |
| configured to | `выполненный с возможностью` | capability language; verify structural support |
| controller | `контроллер` / `блок управления` | select once and preserve the distinction |
| neural network / model | `нейронная сеть` / `модель` | identify what kind of model is meant |
| training data | `данные для обучения` | distinguish training, validation, and test data when disclosed |
| classifier / detector | `классификатор` / `детектор` | preserve algorithmic distinction |
| input / output | `вход` / `выход`; `входные` / `выходные данные` | use consistently by context |

At first use, expand non-standard abbreviations. Do not create a Russian abbreviation
that the draft does not need. Maintain a reference-numeral table separately from the
terminology map so a name change is propagated to every figure and section.
