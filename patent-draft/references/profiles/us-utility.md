# U.S. utility drafting profile

This foundation profile establishes routing and artifact boundaries. Its substantive
drafting reference will be added separately.

Use it only for a U.S. utility application in English. It supports new drafting and
supported revision. It does not support EN-to-RU adaptation.

Apply the common evidence, claim-first, and deliverable contracts. Do not treat this
foundation file as a substitute for current U.S. law or the repository's detailed
`patent-audit` skill. Until the substantive drafting reference is installed, mark
jurisdiction-specific drafting conclusions as unavailable rather than importing a
rule from another profile.
