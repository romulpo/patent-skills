# U.S. utility drafting profile

Use this profile only for a U.S. utility application drafted in English. It supports
new drafting and supported revision. It does not support EN-to-RU adaptation.

Read, in order:

1. [../us/source-manifest.md](../us/source-manifest.md) and
   [../us/authority-and-verification.md](../us/authority-and-verification.md);
2. [../us/specification-drafting.md](../us/specification-drafting.md);
3. [../us/claim-drafting.md](../us/claim-drafting.md); and
4. [../us/software-ai-drafting.md](../us/software-ai-drafting.md) when software,
   machine learning, or AI is material to the contribution.

Apply the common evidence, claim-first, and deliverable contracts. Do not import a
Russian drafting convention unless the U.S. references independently support the
choice. Keep this drafting profile separate from the repository's filing-oriented
`patent-audit` skill. Return the completed `us-rule-check.md` with the packet and
complete the verification gate before a filing-facing handoff.
