# Russian invention drafting profile

Use this profile only for a Russian invention draft in Russian. It supports new
drafting, supported revision, and EN-to-RU translation/adaptation.

Read, in order:

1. [../ru/source-manifest.md](../ru/source-manifest.md) and
   [../ru/authority-and-verification.md](../ru/authority-and-verification.md);
2. [../ru/core-drafting.md](../ru/core-drafting.md);
3. [../ru/invention-drafting.md](../ru/invention-drafting.md);
4. [../ru/terminology.md](../ru/terminology.md) when drafting IT or translating;
5. [../ru/translation-review.md](../ru/translation-review.md) only in
   `translate_adapt` mode.

Apply the common evidence, claim-first, and deliverable contracts. Keep every
claim family inside the Russian invention object categories and unity analysis.
Do not import U.S. claim conventions unless the RU references independently support
the choice. Mark the result as an AI-assisted drafting packet, not filing-ready
legal advice; complete the verification gate in the source manifest before a
filing-facing handoff. Return the completed `ru-rule-check.md` with the drafting
packet.
