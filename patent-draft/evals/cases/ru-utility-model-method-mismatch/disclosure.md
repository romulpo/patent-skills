# Synthetic inventor disclosure: duplicate-event filtering

This fictional disclosure is supplied only for skill evaluation.

The inventors describe a sequence performed by ordinary server software. The
software receives event records, groups records having the same source identifier
and timestamps within two seconds, retains the record having the longest payload,
and deletes the remaining grouped records. The sequence reduces duplicate entries
in a database.

No server architecture, special hardware, sensor arrangement, storage topology,
module structure, or physical relationship is disclosed. The technique has only
been expressed as the sequence above.
