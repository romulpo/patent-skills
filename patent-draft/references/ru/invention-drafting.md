# Russian invention-specific drafting

## Object and claim-family selection

Russian invention practice permits product, method, and application objects. The
supplied corpus particularly supports devices/systems, methods, programmable
multifunctional means, and machine-readable media. Confirm the intended object for
each independent claim before drafting. `[LAW RU-INV-107 §42]`

Multiple independent claims are not a default. Use them only when the planned group
meets the unity requirement and an allowed relationship. Record the common or
corresponding special technical feature in the claim plan. Do not make independent
claims refer to each other merely to save drafting effort.
`[LAW RU-INV-107 §§2,63–65,68]`

Alternative limitations may be used only when every alternative, with the remaining
features, obtains the same technical result and each alternative is supported. Map
support and result separately for every branch. `[LAW RU-INV-107 §§53(2),62(8)]`

## Claim expression

- Draft a device or system in a static state. Functional capability language may be
  used when it characterizes a supported technical capability; ensure the
  description explains how the disclosed structure performs it.
  `[LAW RU-INV-107 §§44,54,62(11)]`
- Draft method actions with verbs in the indicative mood, third-person plural, such
  as `получают`, `обрабатывают`, and `формируют`.
  `[LAW RU-INV-107 §62(20)]`
- For an IT method, identify supported input/output operations, computational or
  logical operations, memory operations, temporal order, conditions, and technical
  means. For AI, capture the supported algorithmic features, processing method,
  parameters, training actions, and training-data preparation.
  `[LAW RU-INV-107 §50(1)]`
- A machine-readable-medium family must be supported as a technical subject in the
  evidence and fit the unity plan. Do not add it mechanically to every software case.
  `[LAW RU-INV-107 §§42,50(1),63–65] [DRAFTING]`

## Technical result and implementation

For software and AI, do not rely only on the meaning of information or on a business
outcome. Prefer a supported result tied to objectively observable technical
parameters or to obtaining data about a material object or process through natural
laws. Record the metric and evidence when the result is stated quantitatively.
`[LAW RU-INV-107 §42]`

When a function is implemented by programmable means, provide supported detail that
lets a specialist understand the implementation. Use supplied block diagrams,
mathematical expressions, algorithm steps, data structures, or short program
fragments where genuinely needed; never synthesize undisclosed code.
`[LAW RU-INV-107 §§50(1),54]`

## Handoff constraint

The source set is drafting-ready for its stated IT/device scope, but it is not a
complete specialist reference for chemistry, biotechnology, pharmaceuticals, or
sequence practice. Mark those cases `VERIFY` and request the relevant authoritative
profile extension before treating the draft as filing-facing.
