# Russian invention drafting profile

This foundation profile establishes routing and artifact boundaries. Its verified
Rospatent drafting reference will be added separately.

Use it only when the selected object is a Russian invention and the output language
is Russian. It supports new drafting, supported revision, and EN-to-RU
translation/adaptation.

Apply the common evidence, claim-first, and deliverable contracts. Do not promote a
local summary, translation guide, U.S. rule, or remembered convention into a
mandatory Russian rule. Until the verified drafting reference is installed, mark
jurisdiction-specific conclusions as unavailable and keep the result explicitly
non-filing-ready.
