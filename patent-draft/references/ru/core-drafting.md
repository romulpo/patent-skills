# Shared Russian drafting rules

These rules apply to both Russian profiles unless the selected profile says
otherwise. Keep source labels in the internal rule-check artifact.

## Description architecture

- Use this order: title; technical field; prior art; disclosure of the invention or
  utility model; brief description of drawings when present; implementation.
  `[LAW RU-INV-107 §33] [LAW RU-PM-701 §33]`
- Keep the title short, precise, tied to the technical purpose, and consistent with
  the selected object and all other application documents. Do not introduce names,
  trademarks, unexplained abbreviations, or promotional language.
  `[LAW RU-INV-107 §§37–39] [LAW RU-PM-701 §§31–32]`
- Cite only prior art and bibliographic facts supplied or independently verified for
  the matter. Identify the closest analogue only when support exists; never invent a
  prototype to force a two-part claim. `[HOUSE-STYLE]`
- State the technical problem, technical result, essential features, and the causal
  relationship between those features and the result. A commercial, administrative,
  aesthetic, or purely informational benefit is not automatically a technical
  result. `[LAW RU-INV-107 §§42–43] [LAW RU-PM-701 §§35–38]`
- Do not replace disclosure of a feature with a reference to an external source.
  `[LAW RU-INV-107 §43(9)] [LAW RU-PM-701 §29]`

## Enablement and support

- Describe at least one supported way to implement the claimed subject and explain
  how it realizes the stated purpose and technical result. For an invention, the
  official requirements call for at least one detailed example; do not fabricate an
  example, test, or measurement when the evidence does not provide it.
  `[LAW RU-INV-107 §§52–54] [LAW RU-PM-701 §38]`
- For a device, describe the construction in a static state and then its operation.
  Keep element names and reference numerals synchronized with the drawings.
  `[LAW RU-INV-107 §§44,54] [LAW RU-PM-701 §§38,40(9)]`
- A claimed range needs support for achieving the result across the range; a claimed
  alternative needs support for the relevant alternatives. If evidence is missing,
  narrow, request evidence, or leave the choice unresolved.
  `[LAW RU-INV-107 §53] [DRAFTING]`

## Claims

- Every claim is one sentence and uses sequential Arabic numbering.
  `[LAW RU-INV-107 §66(1)] [LAW RU-PM-701 §41(1)]`
- Start an independent claim with a generic concept reflecting the purpose of the
  claimed subject. Include a technically coherent set of essential features that is
  supported by the description. `[LAW RU-INV-107 §§62(2–4),66] [LAW RU-PM-701 §§40–41]`
- Use a limiting/distinguishing structure and `отличающийся тем, что` only when a
  supported prototype analysis warrants it. If no analogue is established, use the
  permitted non-divided form rather than inventing prior art.
  `[LAW RU-INV-107 §66(2)] [LAW RU-PM-701 §41(2)]`
- A dependent claim begins with the abbreviated generic concept, identifies its
  parent, and adds a supported particular implementation without replacing or
  excluding a parent limitation. `[LAW RU-INV-107 §§66(4),67] [LAW RU-PM-701 §41(4)]`
- Do not use a drawing or an external reference as a substitute for words expressing
  a claim limitation. `[LAW RU-INV-107 §62(5),(10)] [LAW RU-PM-701 §40(5),(8)]`

## Abstract and consistency

- Draft the abstract for information only. Include the title, field, technical
  problem, technical result, and all essential features reflected in the independent
  claim. The recommended length is up to 1,000 printed characters.
  `[LAW RU-INV-107 §§77–80] [LAW RU-PM-701 §48]`
- Use one preferred Russian term for one concept across claims, description,
  abstract, figures, and translation-review findings. Record justified exceptions in
  the terminology map. Expand an abbreviation at first use and use SI units unless a
  supported exception applies. `[LAW RU-INV-107 §§5–6] [TRANSLATION]`

## Final drafting checks

Before returning a clean draft, verify claim support, dependency, one-sentence form,
object category, terminology, values and units, drawing references, title, technical
result, and unresolved decisions. A missing fact remains visible; fluent prose does
not cure unsupported matter.
