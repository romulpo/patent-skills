# Synthetic inventor disclosure: predictive maintenance

This fictional disclosure is supplied only for skill evaluation.

server stores the received values together with timestamps. The inventors want the
system to predict pump failure 30 days in advance with at least 95 percent accuracy.

training procedure, inference rule, threshold, dataset, test result, or explanation
